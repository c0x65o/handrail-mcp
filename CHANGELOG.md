# Changelog

## 0.2.4

- Bug and enhancement submit accept 4 attachments, 5 MiB each and 15 MiB combined. The Node MCP HTTP transport accepts 25 MiB JSON requests.
- Apps can mount a raw upload handler and pass short, user-scoped upload IDs to the existing submit tools.
- Apps can opt into owned add, list and fetch attachment tools once Handrail enables their verified app invocation routes.
